# v0.2.0 fixture sources

Author: Links Tam. License: MIT (repository LICENSE).

- `V020-*.roomfit`: generated from the editable generic templates in app/src/lib/roomfit/templates.ts. Fictional example layouts, not surveyed residences or manufacturer catalogs.
- `app/static/roomfit-example-plan.png`: original raster drawing with illustrative 4000 mm / 3000 mm reference annotations. The finished room depends on reviewed wall centerlines and thickness, not only the printed bounding dimensions.
- `V020-irregular-plan.png`: original L-shaped raster fixture with 4200 mm / 3150 mm annotations.
- `V020-blurred-plan.png`: Gaussian-blurred version of the example, used to verify that failed OCR leaves manual calibration available.
- `V020-slanted-plan.png`: affine-sheared example, used for degraded recognition and manual fallback tests; no automatic perspective accuracy is claimed.
- `V020-dimensioned-plan.pdf`: two pages containing the above original raster plans, generated by app/tests/v020-ocr-fixtures.mjs. OCR reads rendered pixels rather than PDF text objects.
- `V020-personal-desk.glb`: original four-part solid-material test desk generated by app/tests/create-personal-fixture.mjs. It tests unit/bounds/origin/material handling and cross-project persistence, not a commercial product replica.

Existing A/B/C/D examples retain their original source notes and limitations. In particular, C has no trustworthy dimension labels, and D is a synthetic RoomPlan format fixture rather than a real phone capture.
