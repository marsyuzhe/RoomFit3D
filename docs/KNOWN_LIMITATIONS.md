# 0.2.0 已知限制

这是可运行的开发发行版，不代表全部长期产品要求已经验收。

1. 150 件目录是作者自建的通用参数化结构模型，尺寸为估算，不是厂商实测模型；软包、织物、玻璃、显示器和细节的写实度仍有限。没有用品牌名称暗示官方资产。继承编辑器里的其它家具不计入 150 件验证数。
2. 本机 OCR 已实际运行，目标是阿拉伯数字及 mm/cm/m 单位。尚无完整中文文字识别、照片透视/歪斜校正、多区域独立比例或任意角度语义墙体模型。模糊/斜拍图仍需人工校准与描墙。门窗亮色缺口只是低置信假设，不是可靠语义识别。未知高度保持估算。
3. PDF 缩略图只展示前 12 页；上一页/下一页仍可访问最多 200 页。工程仅保存当前页栅格，之后换页需要原文件。
4. 个人 GLB 支持内嵌、无压缩、无骨骼、无贴图的纯 PBR 网格；不支持纹理打包、动画、Draco/meshopt、外部资源。导入会明确拒绝不支持项；已接受的几何保持比例并进入同一 Cycles 导出。个人照片仅为资料。
5. 家具间碰撞采用构件包围体，曲面仍为保守近似；不是所有三角形的精确实体布尔检测。柜门/抽屉、座椅后退、支撑及窗台检查属于规则提示，没有真实五金运动、承重、人体或规范认证。没有连续通路分析。
6. RoomPlan JSON/ZIP 导入可用，一层一个项目。没有附带 iPhone/iPad 扫描采集程序、Windows 手机扫描端、现场 LiDAR 或 AR 实测结果。扫描样例是格式测试数据，不能证明传感器精度。
7. RoomScene 未完整接入多层、内孔、复杂曲墙及特殊门；原始高级编辑器较广的能力不等于毫米场景已经全部支持。变更后请核对回传几何。
8. 方案快照是本地恢复数据，尚非跨设备多方案容器；没有持久渲染队列/历史、真实 HDRI、地理日照、照片重建、整屋 GLB/OBJ 导出或施工图级 PDF。SVG/PDF 仍以布局和家具清单为主。
9. 安装包未签名，不内置 Blender；需另选官方 Blender 4.5+。本次在当前 Windows 实机自动化验证，没有干净虚拟机安装/卸载、真人可用性研究、长时间大型住宅、CPU 回退或显存耗尽故障注入验收。显示缩放测试使用实际 Electron 的缩放参数，不改用户系统设置。
10. 性能数字来自本机自动化测量，包含 Playwright 的等待开销；RAF 时间不是独立 GPU 吞吐 FPS。撤销历史会保留 JSON；资源销毁事件与堆数据不能代替长时间泄漏测试。
