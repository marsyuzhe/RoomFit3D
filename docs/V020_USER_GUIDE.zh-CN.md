# 0.2.0 新手使用说明

作者 Links Tam。双击工作目录的“启动 RoomFit 3D.cmd”，或安装 dist 中的 0.2.0 安装包。右上角可切换简体中文与 English。

## 从房间开始

首页有三个入口。知道房间净尺寸时选“输入房间尺寸”；有图片/PDF 时选“上传户型图”；想先试搭配时选“选择装修模板”。模板均为虚构示例，家具与房间尺寸仍需现场确认。“最近编辑”继续本机恢复项目。熟练后可以勾选下次直接进入编辑器。

## 从图纸建房

1. 选择、拖入或粘贴图纸。PDF 可预览页面；旋转或裁切后需要重新校准。
2. 点击“识别图中尺寸”。OCR 在本机运行。橙框是文字位置，不是测量线：核对候选值及单位，点击候选，然后点实际尺寸线两端，记录比例。再用另一处尺寸复核。没有候选时仍可手工输入长度。模糊、斜拍和低分辨率图纸可能识别错误。
3. 提取候选墙线，删除误检，拖动端点，连接或用“两点补线”补出闭合轮廓。绿色表示本次采用，红色表示排除；不代表算法已经验证现场。无法闭合时可先附加底图，再进入成熟绘墙工具。
4. 检查门窗缺口候选，或手动选墙、类型、位置、宽高和窗台。门窗线可在图上拖动位置。候选不会自行加入。门高、窗台、开启方向均应人工复核。
5. 看三维预览；返回修正或进入装修。未确认的比例保持“估算”提示。单页底图保存在项目里；以后换 PDF 页时须重选原文件。

## 选家具和搭配

左侧按分类、风格或中英名称搜索，例如“电竞桌”“desk”“monitor”“wardrobe”。点击卡片添加；预览按钮打开可旋转的实际模型。星号收藏、最近使用和个人家具保存在本机，不需账户。

选中家具后使用浮动工具栏旋转、复制、删除、锁定、改色或每次移动 50mm。右侧尺寸可输入 120cm、1.2m、1200mm；纯数字默认毫米。明显异常尺寸会报错并保留原值。请把商品尺寸、品牌、型号和链接录入，并选择对应的尺寸来源。

先选择桌子再添加显示器、键盘等桌面物件，会建立支撑关系；之后桌子变高或转动时设备跟随。也可在“家具支撑关系”选择桌子或独立放置。拖动附着物会将其独立放置。快速替换保留位置、朝向、颜色与支撑关系，并重新计算检查结果；锁定物件不能被替换。

柜体可改列数/层数，实际隔板会重建。RGB 物件可开关、改色、调强度、选择预设。灯具另有色温参考输入，它转换为近似颜色，不代表真实光谱标定。相同参数进入实时预览与 Cycles。

## 个人家具

展开左下“我的家具”，填写自己的名称、尺寸、参考照片和商品资料后保存。照片用于资料，不会自动还原成三维模型。可选通用结构，或导入自己的 GLB。GLB 支持内嵌、无压缩、无动画、无贴图的纯 PBR 材质；先确认单位与朝向，再检查模型尺寸。原点会移到家具中心和地面。导入后必须保持原始比例，不能任意压扁。导入错误会明确显示原因，原项目仍可编辑。

## 检查、出图和保存

空间检查区区分几何问题和建议。家具间检查使用构件包围体，L 桌有 L 形轮廓；曲面和软装仍为保守近似。桌下空隙不会仅因整件外框重叠就认定碰撞。柜门/抽屉和座椅退让距离是建议，并非建筑规范或真实五金运动仿真。尺寸未经确认时，不应把“未发现问题”理解为已验证适配。

选“室内”构图，再到“出图”设分辨率、采样和日夜环境，启动高清渲染。运行在本机 Blender Cycles；失败时看任务日志，可以继续编辑。结果页可查看和保存原图。安装包不附带 Blender，首次使用可在渲染器设置选官方 Blender 4.5+。

保存为 .roomfit 文件即可保留场景、底图与引用模型。旧 v1/v2 项目可读取并升级为 v3；旧应用无法完整理解新字段。方案快照目前保存在本机恢复数据，不是跨设备项目容器。
