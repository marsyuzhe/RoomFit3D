# Security

This pre-release has no published support lifecycle or response SLA. Do not post secrets, private floor plans or exploit details in public Issues. If the repository owner has enabled GitHub private vulnerability reporting, use Security → Report a vulnerability. Otherwise ask for a private reporting channel without disclosing the details; no private email address is currently supplied.

Use official downloads and verify SHA-256. The installer is unsigned. Models and images are untrusted input; do not open files from unknown sources with disabled system protections. Rotate any credential you have already disclosed; removing a copy does not revoke it.
