# Contributing

Read README and docs/BUILD.md, then run the documented tests before proposing a change. Keep changes focused; explain visible behavior and include real screenshots for UI changes. Use Issues for reproducible non-sensitive bugs and feature discussion; maintainers have not promised response times.

Preserve Links Tam’s and upstream authors’ copyrights. Include provenance and a compatible license for assets. Never submit API keys, personal floor plans, user photos, compiled caches or node_modules. Main scene units are millimetres; only openplanAdapter.ts crosses into the inherited centimetre editor. Three.js and Cycles must use the same buildScene meshes.
